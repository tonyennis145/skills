# Skills

Claude Code skills. Each folder is one skill, with a `SKILL.md` as its entry point.

| Skill | What it's for |
|---|---|
| [mini-apps](mini-apps/SKILL.md) | Building lightweight team apps as a single `index.html` (Preact + htm, no build), synced through TinyBase on a Cloudflare Worker, with an optional zero-dependency `server.mjs` and Giga for credentials. **First draft, needs review.** |

To use one, copy its folder into `~/.claude/skills/` (or your project's `.claude/skills/`).
